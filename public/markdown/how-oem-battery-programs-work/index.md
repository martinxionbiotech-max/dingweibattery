# How OEM battery programs work

Published by Dingwei Battery · Last reviewed 2026-09-01 · Source: Chengguang Power Tech Co., Ltd. technical documentation

An OEM battery program is a repeatable supply arrangement, not a one-off order. It runs in four phases.

**Short answer:** An OEM battery program runs in four repeatable phases: specification, sampling, production and repeat orders. The buyer signs off the specification and sample, while the manufacturer locks that approved standard so subsequent containers match the first approved unit.

## 1\. Specification

You define the battery: standard, model, capacity, CCA, terminal, label and packaging. The manufacturer confirms it against their production capability.

## 2\. Sampling

The manufacturer produces pre-production samples for your testing and approval before mass production.

## 3\. Production

Approved specification goes to the production line. Chengguang Power Tech Co., Ltd. runs 18 automated lines with IATF 16949 quality control and 100% end-of-line testing.

## 4\. Repeat orders

The specification is locked so subsequent orders match the approved sample. Repeatability is the point of an OEM program.

## The four phases at a glance

| Phase | What is produced | Buyer checkpoint |
|---|---|---|
| Specification | Written spec sheet | Sign every parameter, including CCA basis |
| Sampling | Pre-production sample | Test before approval; keep the record |
| Production | Container-load batches | Confirm schedule and change freeze |
| Repeat orders | Identical follow-on batches | Re-check against the approved sample |

## The specification lock

The core of an OEM program is not the first order; it is the locked specification that makes the tenth order match the first approved sample. Without a lock, a repeat order becomes a new development project with fresh approval risk.

Define the lock as the buyer-approved sample plus written parameters and change control. The [OEM development process](/knowledge/oem-battery-development-process/) shows where each gate must be signed before the lock is released to production.
