# OEM battery specification guide

Published by Dingwei Battery · Last reviewed 2026-09-01 · Source: Chengguang Power Tech Co., Ltd. technical documentation

A battery specification is only as useful as the fields you fix in advance. This guide explains each field buyers should confirm.

**Short answer:** A usable OEM battery specification fixes the standard family, voltage, capacity, CCA with its test basis, dimensions, terminal type and polarity. Never compare CCA values without stating whether they are JIS (−15°C) or EN (−18°C).

## Standard family

Start with the standard your vehicles use: JIS, DIN, BCI, AS, SA. JIS models such as 65D26 and DIN/EN models such as H6 describe different naming and test conventions.

## Voltage

Passenger-car starter batteries are usually 12V; heavy-duty applications can also use 6V. Confirm the system voltage of the target vehicle.

## Capacity (Ah)

Capacity describes the battery’s energy content over a defined discharge test. It must be read with the standard because the same physical size can carry different ratings across families.

## CCA

Cold cranking amps indicate starting performance at low temperature. CCA values are test-method dependent and must carry a reference basis — for example JIS (-15°C) or EN (-18°C). Always confirm final CCA with the manufacturer before ordering.

## Dimensions, terminal and polarity

Fix length × width × height in millimetres, terminal type and polarity. If a field is not yet known, mark it “confirm on inquiry” rather than guessing.

## CCA: two numbers for one battery

Cold cranking ampere values only compare when the test method is stated. The same battery can carry a lower JIS number and a higher EN / SAE number because each method uses a different test condition.

| Test method | Temperature | Note |
|---|---|---|
| JIS | −15°C | Lower number; common in Asia |
| EN / SAE | −18°C | Higher number; international |

These are not directly convertible. Always state the test method next to a CCA value when issuing an RFQ.

## The specification fields that actually matter

-   Standard family and model reference
-   Voltage and capacity
-   CCA with its test basis
-   Case size and terminal type
-   Polarity
-   Label and packaging requirements

Put those fields into the [OEM battery RFQ guide](/knowledge/oem-battery-rfq-guide/), then check the responses against the [supplier checklist](/knowledge/oem-battery-supplier-checklist/).

## Specification drift: the hidden risk

Specification drift happens quietly on a repeat order: the approved sample is replaced by a different grid alloy, a shorter curing time, or an unapproved terminal change. The buyer only notices when the new container tests differently from the first one.

The only durable control is to lock the approved specification and require formal change control for any deviation. Put that control in writing using the [supplier checklist](/knowledge/oem-battery-supplier-checklist/) before production restarts.

## CCA: why one battery has two numbers

A single battery can show two CCA values because JIS (−15°C) and EN / SAE (−18°C) are different test methods, not a “high” and a “low” rating. If the RFQ does not state the test method, two suppliers can appear to be quoting different batteries when they are quoting the same product on different bases.

State the basis on every line and compare only same-method values. See how that instruction fits into the wider request in the [OEM battery RFQ guide](/knowledge/oem-battery-rfq-guide/).
